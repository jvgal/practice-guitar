# practice-guitar

App de estudo de guitarra, grátis e open source. Roda no navegador, sem instalar nada, funciona offline.

**Online:** https://jvgal.github.io/practice-guitar/ · [Read in English](README.md)

## Exercícios

- **Metrônomo** com as 7 células rítmicas (colcheias, shuffle, tercinas, semicolcheias, galopes, sincopada), notação ao vivo e BPM ajustável.
- **Braço interativo** — escala + acorde nos 5 shapes do CAGED, com opção de **ciclar as 4ªs** trocando o shape junto (G→C→F… / E→D→C…).
- **Escalas nota a nota** — ouve cada nota, vê nome e grau no braço. Maior, menor natural, menor harmônica, pentatônica menor/maior e blues.
- **Conectar os shapes** — sobe a escala pelas 5 posições, pelo braço inteiro.
- **Montar escala** (`scale-builder.html`) — preenche os graus, envia pra validação e recebe uma nota.
- **Aquecimento cromático** (`warmup.html`) — 1-2-3-4 e permutações de dedos.

A interface do app é em inglês.

## Rodar

É só abrir o `index.html` no navegador. Sem build, sem dependências — HTML puro + JS vanilla, Web Audio API e SVG.
